# hivemind-worker

Python 3.13 lab agent and worker CLI for the disposable Ubuntu lab host (D-030, D-034).
Stage 02 ships the agent: generated Pydantic contracts, the `container.linux` and
`network.containerlab` providers, per-node PTYs, host safety, heartbeat and
reconciliation against the session Worker, and the worker CLI. Faults, graders, and
reference solutions arrive in Stage 03.

```bash
uv sync                      # create .venv with pinned tools
uv run task verify           # ruff, pyright, contract drift check, pytest
uv run task generate         # regenerate hivemind_worker/contracts from ../../schemas
uv run pytest -m docker      # provider tests against a Docker daemon (Linux CI, lab host)
uv run hivemind-worker --help
```

## Layout

```text
hivemind_worker/
  agent/        aiohttp server (jobs, health, PTY WebSockets), job runner, callback client,
                reconciliation and orphan sweeper, Access JWT verification
  providers/    container.linux (Docker), network.containerlab (containerlab + FRR), PTY bridge
  safety/       default-deny egress rules (iptables), cgroup/pid limits
  topology/     LabSpec → containerlab topology, FRR daemons/frr.conf, node startup commands
  contracts/    generated from ../../schemas (D-043); never edit by hand
  config.py     environment → WorkerConfig (see deploy/worker.env.example)
  protocol.py   helpers over the worker-protocol models
deploy/         systemd unit and the environment file template
images/         hivemind/linux-lab Dockerfile (base pinned by digest)
tests/          unit tests (no Docker) plus `docker`/`containerlab` marked integration tests
```

## Protocol (worker protocol v1, `schemas/WorkerEnvelope.schema.json`)

- The session Worker pushes jobs to `POST /jobs` on the Tunnel hostname; the agent
  answers 202 and runs them in the background.
- The agent reports `event.status`, `event.log`, `event.result`, and `event.error` to
  `POST /session/worker/events`, heartbeats to `/session/worker/heartbeat`, and
  reconciles through `/session/worker/reconcile`, always with its service token.
- PTYs: `GET /sessions/{id}/nodes/{node}/pty` upgrades to a WebSocket; binary frames are
  terminal bytes, text frames are `PtyControlMessage` JSON (`resize`, `ready`, `exit`,
  `error`). A PTY outlives its socket; reconnecting replays the scrollback.

## Safety (D-001, RFP §85)

Per-session Docker network (internal when egress is denied, otherwise DOCKER-USER rules
with an allowlist), CPU/memory/pid limits from the lab spec, capabilities dropped except
what a routing exercise needs, no host Docker socket, a hard TTL label on every container,
and an orphan sweeper that destroys anything the session Worker no longer expects.

`hivemind_worker/contracts/` is generated by `datamodel-code-generator` (D-043) from the
JSON Schema exported by `packages/schema`; never edit it by hand. CI fails on drift.
