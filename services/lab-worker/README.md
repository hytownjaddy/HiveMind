# hivemind-worker

Python 3.13 lab agent and worker CLI for the disposable Ubuntu lab host (D-030, D-034).
Stage 01 ships the skeleton: generated Pydantic contracts, the CLI surface, and the
round-trip test against `schemas/fixtures/`. Providers, faults, graders, and reference
solutions arrive in Stages 02–03.

```bash
uv sync                      # create .venv with pinned tools
uv run task verify           # ruff, pyright, contract drift check, pytest
uv run task generate         # regenerate hivemind_worker/contracts from ../../schemas
uv run hivemind-worker --help
```

`hivemind_worker/contracts/` is generated by `datamodel-code-generator` (D-043) from the
JSON Schema exported by `packages/schema`; never edit it by hand. CI fails on drift.
